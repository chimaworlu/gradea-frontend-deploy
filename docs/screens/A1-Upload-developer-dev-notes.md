# A1 Upload: developer notes

- **How a guest gets here (19 Nov):** from "Get started" in the marketing nav and other buttons that are not an upload box. The upload boxes on the marketing pages skip this page.
- **No scan button for guests on the General tab:** choosing or dropping a CV goes straight to the signup wall. The guest "File chosen" frame was removed. While the file uploads, "Uploading..." shows as a plain status line with a spinner (no button). If the upload fails, the error shows with a "Try again" button.
- **Guest Job-specific frames** ("A1 / Upload / Guest / Job-specific ...", same seven states as the Free ones): guest top bar ("Log in" only), no career level line (guests choose it on the signup wall), no scans-left line, and the "Match my CV" button stays, because the job description is needed first. The button is the trigger to go to the signup wall.
- **Signed-in Free and PRO frames** keep "Scan my CV", because there is no wall.

- **Whole-page drop zone:** the page, not only the upload box, accepts a dropped file. As soon as a file enters the page, the upload box switches to its "dragging over" look. If a file is dropped outside the box, it is still handled as an upload. Without this, a missed drop makes the browser open the file in the tab and the user leaves the site.
- **Top bar for guests on this page:** "Log in" only, as a small secondary button (36px tall, white fill, 1px #677B98 outline, navy text, 8px corners). No "Get started" button, because the visitor is already on the page where they start.
- **Signed-in users:** the top bar shows the account avatar (menu designed in S2). The career level line shows the stored profile default; "Change" applies to this scan only and does not change the stored default.
- **Scans-left line:** shown to Free users only, per mode (General or Job-specific). PRO users do not see it. Always neutral grey text, never a warning color.
- **Prices in the limit popup (and everywhere):** the Day Pass price and currency come from the plans endpoint, never hardcoded. Users detected in Nigeria see naira (for example "Day Pass from ₦900"), everyone else sees dollars ("Day Pass from $2.99"). The Figma frame shows the Nigeria version. If the user has switched currency on the pricing page, the popup uses that choice.
- **Job link helper text:** names only sites that have been tested and work (planned: Greenhouse, Lever, BambooHR).
- **Reading a job link:** reading starts by itself when a link is pasted or the field loses focus. The input stays editable, and changing the link starts reading again. If reading takes longer than about 8 seconds it counts as failed.
- **"Review text":** after a successful read, this switches to the "Paste text" tab and shows the captured job text so the user can check and edit it.
- **Keep what was typed:** switching between General and Job-specific keeps the chosen CV. Switching between "Paste text" and "From a link" and back keeps what was typed in each.
- **Link error messages (same layout, text swap):** (1) could not read it: "We couldn't read that link. Paste the job description text instead." (2) site not supported: "We can't read links from that site yet. Paste the job description text instead." (3) not a link: "That doesn't look like a link. Check it and try again." The "Paste text" button on the first two switches to the "Paste text" tab and focuses the text area.
- **Pasted job description checks (same layout, text swap):** under 100 characters: "That looks too short to be a job description. Paste the full post." Over 15,000 characters: "That's too long. Paste only the job description." Both limits are starting values and can be adjusted. The button stays active; the check runs when the user taps "Scan my CV", and the error clears when the text changes.
- **Job-specific limit popup:** same popup as General, text swap only. Title: "You've used your Job-specific scan for this month". The body says it resets on the reset date. Final words go in content/app/upload.json.
- **Button states:** primary hover #16304F, pressed #102540 (the only two added navy shades, used only on button states). Secondary hover #EEF2F7, pressed #D8E4F3. Focus ring is 2px navy with a 2px gap on every button. Disabled is the same shape at 40% strength. Loading primary shows a white spinner and "Scanning...", and cannot be tapped. Text button hover and pressed add a 1px underline.
- **Input and text area states:** hover outline goes navy #1E3A5F. Focus is a 2px navy outline plus a second 2px navy ring with a 2px gap, no glow. Error is a solid 1px red #BC1010 outline with an alert icon and a red message under it. Disabled (link field only, while reading) uses fill #EEF2F7 and 40% outline and text.
- **Switch states:** selected is #D8E4F3 with navy text and a 1px navy outline, and does not change on hover or pressed. Unselected hover is #EEF2F7, pressed is #D8E4F3. Focus is the 2px navy ring with a 2px gap.
- **Upload box states:** empty is a dashed 1.5px #677B98 outline. Hover turns the dashed outline navy with fill #EEF2F7. Dragging is a solid 2px navy outline (drawn inside) with fill #EEF2F7 and the title "Drop your CV to upload". File chosen is a solid 1px #E3E0D6 outline. Error is a solid 1px red outline with the message under the box.
- **Limit popup behaviour:** a dim layer (ink at 40%) covers the page. Focus moves into the popup when it opens and stays inside it. Escape, the close X and "Maybe later" all close it. Focus returns to the "Scan my CV" button.
