# A3 Signup wall: developer notes

- **Working state:** while the invisible checks run (throwaway-domain blocklist, email can receive mail, bot check), the Google button, divider and all three fields drop to 40% and cannot be changed or tapped. The primary button stays navy with a white spinner and "Creating your account...", and cannot be tapped again. Never say "Verifying".
- **Email errors (same layout, text swap):** (1) throwaway domain: "Please use a real email address." (2) domain cannot receive mail (typo such as gmial.com): "We can't find that email domain. Check for typos." (3) account exists: "That email already has an account." followed by a navy "Log in" link that goes to the login page with the email filled in. The error shows under the email field with a solid 1px red #BC1010 outline. The button returns to its normal state so the user can fix the email and try again.
- **Password rule:** at least 8 characters, no symbol or capital-letter demands (starting value, can be changed). Error: "Use at least 8 characters." The password stays hidden, and the eye icon toggles it.
- **Career level list:** options are Entry-Level, Mid-Level, Senior, Executive. Rows are 44px tall. Hover row #EEF2F7. The selected row is #D8E4F3 with a navy check. The list opens 4px under the field at the same width, with the one soft shadow. It supports keyboard use (arrow keys, Enter to choose, Escape to close). If skipped, the error under the field reads "Choose your career level." (same layout as the other field errors). Open question for later: add a short helper under each choice (for example a years range) once the ranges are decided.
- **Generic failure:** if signup fails for any other reason, show "Something went wrong. Try again." as a red line above the button, same layout as the field errors. The form stays filled in.
- **Google sign-in cancelled or failed:** show "Google sign-in didn't finish. Try again." as a red line above the Google button, same layout as the other errors. The form stays as it was.
